## Структура проекта и описание файлов

Проект разделен на директории, содержащие материалы соответствующих практических работ.

### Pract1
*Анализ данных и машинное обучение (алгоритм KNN)*

**Скрипты (Jupyter Notebooks)**
- **`Converter.ipynb`** — файл предварительной обработки данных. Выполняет очистку сырых ответов, векторизацию множественного выбора, One-Hot кодирование текстовых категорий, Z-масштабирование числовых переменных и конвертирует исходный `.xlsx` в нормализованный `.csv` датасет.
- **`Main.ipynb`** — основной скрипт с моделью машинного обучения. Содержит загрузку подготовленного датасета, разделение выборки на обучающую и тестовую, обучение алгоритма KNN, расчет метрик точности и визуализацию матрицы ошибок.

**Наборы данных (Data)**
- **`Survey_Results_Plain.xlsx`** — исходные сырые данные опроса.
- **`NN_Training_Dataset.csv`** — нормализованный числовой датасет без пропусков, готовый для подачи на входной слой модели (результат работы `Converter.ipynb`).

---

### Pract2
*Анализ социального графа и расчет метрик центральности*

- **`Pract2.ipynb`** — скрипт для анализа социальных связей. Выполняет загрузку датасета, инициализацию графа с помощью библиотеки `networkx`, расчет метрик центральности (посредничество, близость, собственный вектор) для выбранных участников группы и визуализацию итоговой сети с использованием `matplotlib` и алгоритма `spring_layout`.

---

### Pract3
*Бинарная визуальная классификация объектов с использованием VLM (Zero-Shot)*

- **`Pract3.ipynb`** — скрипт для классификации типов часов (классические или умные). Выполняет локальную загрузку моделей архитектуры CLIP от OpenAI через библиотеку `transformers`, прямой инференс изображений и расчет сравнительных метрик точности (`accuracy`, `precision`, `recall`, `f1-score`) для базовой и увеличенной версий модели.
- **`Watches/`** — директория, содержащая сбалансированный локальный датасет из 20 изображений часов. Выборка специально подобрана с учетом нетривиальных пограничных случаев (гибридные смарт-часы, электронные ретро-модели, классический дизайн смарт-часов) для проверки устойчивости нейросетей к мимикрии дизайна.
